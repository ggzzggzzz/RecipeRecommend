## 🧾 프로젝트 소개

바쁜 일상 속에서 식재료를 효율적으로 활용하지 못하는  
**1인 가구 및 자취생**을 대상으로,  

> ✅ **보유한 식재료로 만들 수 있는 요리 메뉴와 레시피를 추천**하고  
> ✅ **레시피별 식재료 가격 정보를 함께 제공**하여  
> 보다 **합리적인 요리 선택**이 가능하도록 도와주는 서비스입니다.
